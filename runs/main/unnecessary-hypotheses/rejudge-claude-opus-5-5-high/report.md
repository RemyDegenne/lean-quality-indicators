Let V := vanishingIdeal (closure (range f)). It is enough to show V.ideal U = RingHom.ker (f.app U) for every affine open U of Y; then `ofIdeals_ideal V` gives f.ker = V.

(⊆) Take s ∈ Γ(Y, U) vanishing on closure(range f) ∩ U. Then X.basicOpen (f.app U s) = f⁻¹ᵁ (Y.basicOpen s) (`Scheme.preimage_basicOpen`). This preimage is empty because Y.basicOpen s misses range f. Since X is reduced, `basicOpen_eq_bot_iff` (Properties.lean, needs [IsReduced X]) gives f.app U s = 0.

(⊇) If f.app U s = 0, the same preimage identity shows that Y.basicOpen s does not meet range f. Y.basicOpen s is open, so it also misses closure(range f). Hence s lies in every prime of Γ(U) that corresponds to a point of the closure, which means s ∈ V.ideal U.

So `(f j).ker = vanishingIdeal (closure (range (f j)))` holds for each j using only `[IsReduced (X j)]`. The theorem then follows as before from `vanishingIdeal_iSup`, which has no extra assumptions. Degenerate cases: if J is empty, both sides are ⊤, since vanishingIdeal ⊥ = ⊤ by `vanishingIdeal_iSup`. If some X j is empty, its kernel is ⊤ and its closure is ⊥, so both sides agree.
